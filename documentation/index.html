Documentation

Everything available in C++ Mode out of the box.

None of these require an #include. They are all automatically available in every sketch through Processing.h.

What is included

C++ Mode includes the full C++ Standard Library automatically. You can use any of the following without writing a single #include at the top of your sketch.

If you want to use a third-party library, you can still add #include statements as normal.

Containers

std::vector

Dynamic array. The most common container. Use instead of Java's ArrayList.

std::map

Key-value pairs sorted by key. Use instead of Java's HashMap.

std::set

Sorted collection of unique values.

std::list

Doubly linked list. Fast insert and remove at any position.

std::deque

Double-ended queue. Fast insert and remove at both ends.

std::queue

FIFO queue adapter.

std::stack

LIFO stack adapter.

Algorithms

std::sort

Sort any container. Works with lambdas for custom comparison.

std::find

Find an element in a range.

std::remove_if

Remove elements matching a condition. Commonly used with vectors.

std::min / std::max

Min and max of two values. Also available as the Processing functions min() and max().

std::accumulate

Sum or fold a range of values.

std::transform

Apply a function to every element in a range.

Strings and IO

std::string

Text string. Use instead of Java's String. Supports +, ==, .size(), .substr() and more.

std::stringstream

Build strings from mixed types. Useful for formatting numbers into text.

std::ifstream

Read from files.

std::ofstream

Write to files.

std::regex

Regular expressions for pattern matching in strings.

std::cout / std::cerr

Print to the console. Also available as println() in Processing style.

Concurrency

std::thread

Run code on a separate thread. Useful for background loading or computation.

std::mutex

Protect shared data between threads.

std::atomic

Thread-safe operations on single values.

Utilities

std::optional

A value that may or may not be present. Avoids null pointers.

std::variant

A value that can be one of several types.

std::tuple

A fixed-size collection of values of different types.

std::pair

Two values grouped together.

std::memory (unique_ptr, shared_ptr)

Smart pointers for automatic memory management.

std::chrono

Time utilities. Measure durations and get the current time.

Math

std::cmath

sin, cos, tan, sqrt, pow, abs, floor, ceil and more. Also available as Processing-style functions.

std::random

Random number generation. Also available as random() in Processing style.

std::numeric

Numeric utilities like iota, accumulate, inner_product.
