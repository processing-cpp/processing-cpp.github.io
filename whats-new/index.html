What's New

C++ Mode is designed to feel as close to Processing Java as possible. Most of what you already know works exactly the same. setup(), draw(), ellipse(), background(), mouseX, mouseY, fill(), stroke() all work the same way. The changes below are the only things you need to learn. Everything else carries over from Processing Java without modification.

Changed
_mousePressed and _keyPressed

In Processing Java, mousePressed is both a boolean variable that tells you if the mouse is held right now, and an event callback function that fires once on click. C++ does not allow a variable and a function to share the same name in the same scope, so the boolean variables are renamed with an underscore prefix to avoid the collision.

The event callbacks keep their original names unchanged. Only the state variables change.

// Check if mouse is currently held down:
if (_mousePressed) { ... }

// Check if any key is currently held down:
if (_keyPressed) { ... }

// Event callbacks are unchanged:
void mousePressed() { ... }
void mouseReleased() { ... }
void keyPressed()   { ... }
void keyReleased()  { ... }
New
captureMouse() and releaseMouse()

captureMouse() locks the cursor to the window and enables raw mouse input, completely bypassing OS acceleration and cursor boundaries. This is the right approach for first-person and shooter games where the mouse needs to rotate a camera freely without hitting the edge of the screen.

releaseMouse() restores normal cursor behavior. Call it when you open a menu, show a dialog, or pause the game.

void setup() {
    size(640, 360, P3D);
    captureMouse();
}

void draw() {
    // camera controlled by mouse freely
}

void keyPressed() {
    if (key == ESC) releaseMouse();
}
New
mouseDX and mouseDY

Two new variables that accumulate raw mouse movement between frames. Unlike mouseX - pmouseX, these capture every cursor event that occurs between frames so fast mouse movement is never dropped or lost at high frame rates.

They reset to 0 automatically after each draw() call. Use them for FPS camera rotation, turret aiming, or any other input that needs to be frame-rate independent.

float yaw = 0, pitch = 0;

void setup() {
    size(640, 360, P3D);
    captureMouse();
}

void draw() {
    yaw   += mouseDX * 0.002;
    pitch += mouseDY * 0.002;
    pitch  = constrain(pitch, -PI/2, PI/2);

    camera(0, 0, 0,
           cos(pitch) * sin(yaw),
           sin(pitch),
           cos(pitch) * cos(yaw),
           0, 1, 0);
    background(20);
    lights();
    box(100);
}
New
Full C++ Standard Library included

Every C++ standard library header is included automatically. You do not need a single #include anywhere in your sketch. Threads, algorithms, containers, all of modern C++ is just there.

// All of this just works with no includes:
std::vector<float> data = {3, 1, 2};
std::sort(data.begin(), data.end());

std::thread t([] { doWork(); });
t.detach();

std::unordered_map<std::string, int> scores;
std::optional<int> val = 42;
