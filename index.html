About

C++ Mode is a plugin for the Processing 4 IDE that brings C++ to the Processing creative coding environment. It lets you write sketches using the same familiar API — setup(), draw(), ellipse(), mouseX — but your code is compiled to a native binary via g++ and runs at full speed without a JVM or interpreter.


It supports Linux and Windows out of the box, handles all the OpenGL setup internally, and fits right into the Processing workflow you are already used to. Missing dependencies like g++, GLFW, or GLEW are detected automatically with a one-click installer.
