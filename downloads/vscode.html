Using C++ Mode in VS Code

Set up either header library download in an external editor and build system, instead of the Processing IDE.

Drag-and-Drop version

The simplest path if your project has no existing build system. Compile a single file directly with g++.

1

Unzip the download into your project folder, alongside your own source files. You should see Processing.h and Processing.cpp.

Screenshot: Processing.h / Processing.cpp in the VS Code file explorer
2

Include the header at the top of your file and write a sketch the same way you would in the IDE:

#include "Processing.h"

void setup() {
  size(640, 360);
}

void draw() {
  background(20);
  ellipse(mouseX, mouseY, 40, 40);
}
3

Open a terminal in VS Code (Ctrl+`) and compile directly with g++:

g++ -std=c++17 sketch.cpp Processing.cpp -o sketch && ./sketch
Screenshot: VS Code terminal compiling and running the sketch

CMake version

For projects that already use CMake, or if you want the engine wired up as a proper library target. Works well with VS Code's CMake Tools extension.

1

Unzip the download and drop the folder into your project (e.g. as a third_party/processing-cpp subdirectory).

Screenshot: project tree with the library folder added
2

Add it to your CMakeLists.txt:

add_subdirectory(third_party/processing-cpp)
target_link_libraries(your_target PRIVATE processing-cpp)
3

If you have the CMake Tools extension installed, VS Code will pick up the project automatically. Use the status bar build/run buttons, or from the terminal:

cmake -B build && cmake --build build && ./build/your_target
Screenshot: VS Code building with CMake Tools

From here, the full reference applies the same way. Every function documented there is available once you've included Processing.h.
