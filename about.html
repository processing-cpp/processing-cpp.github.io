About

C++ Mode for Processing is a plugin for the Processing 4 IDE that lets you write sketches in C++ instead of Java. The goal is simple: bring the accessibility and immediacy of the Processing creative coding environment to the C++ language.

Why C++ Mode?

Learning C++ can feel daunting. The language is powerful but the barrier to getting something on the screen is high. You have to set up a build system, configure a window, initialize an OpenGL context, and write a lot of boilerplate before you draw a single circle.

Processing removes all of that friction for Java. C++ Mode does the same for C++. You open the IDE, type ellipse(300, 300, 50, 50), hit Run, and a window appears. The full OpenGL setup, the event loop, the frame timing — it is all handled for you.

A gentler path into C++

If you already know Processing, you already know most of the API. setup(), draw(), background(), mouseX, fill() — it all works the same way. The only difference is that you are writing C++ now. That means you can focus on learning the language rather than fighting the environment.

C++ Mode is designed to be a gentle on-ramp. Start by writing sketches that look almost identical to your Processing Java sketches. Then gradually introduce C++ concepts as you go — structs, vectors, pointers, templates — at your own pace, in a context that is already familiar and visual.

For everyone

C++ Mode is for artists and designers who want to go deeper. It is for students who are learning C++ and want a creative way to practice. It is for developers who know C++ and want the immediacy of the Processing workflow. And it is for anyone who is curious about what their sketch looks like when it runs at full native speed.
